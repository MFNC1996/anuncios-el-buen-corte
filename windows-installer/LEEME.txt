CARTELERA EL BUEN CORTE — Instalador para Windows
===================================================

CÓMO INSTALAR
--------------
1. Asegúrate de que este PC tenga internet la primera vez (solo se usa una
   vez, para bajar una pieza necesaria de la base de datos).
2. Haz doble clic en INSTALAR.bat
3. Espera a que termine (puede tardar uno o dos minutos).
4. Listo. Vas a ver un ícono "Cartelera El Buen Corte" (con el logo del
   local) en el Escritorio.

La cartelera va a quedar funcionando en:
  http://localhost:4010/admin   (panel para cambiar precios y fotos)
  http://localhost:4010/player/1   (pantalla para mostrar en la TV)

Se instala en tu carpeta de usuario, no necesita que seas Administrador del
PC. Y queda configurada para arrancar sola cada vez que se prende el PC —
no hay que abrir nada a mano todos los días.

El panel se abre como una ventana propia (con el logo del local como
ícono en la barra de tareas), no como una pestaña más del navegador — así
no se confunde con otras ventanas abiertas.

CÓMO DESINSTALAR
------------------
Abre el menú Inicio → carpeta "Cartelera El Buen Corte" → "Desinstalar".
(O ejecuta DESINSTALAR.bat dentro de la carpeta donde quedó instalada,
normalmente en %LOCALAPPDATA%\CarteleraElBuenCorte).

OJO: desinstalar borra también las fotos y los precios guardados. Si quieres
guardar una copia antes, copia la carpeta "server\data" y "server\uploads"
de adentro de la instalación.

¿LA TV ES SAMSUNG?
-------------------
En el panel, pestaña "TV" → "TV Samsung (Tizen)", hay un botón para instalar la cartelera directo en la
TV por wifi. Para que funcione, primero hay que instalar (una sola vez) el SDK de Tizen en este PC:
ejecuta "instalar-tizen-studio.bat" dentro de la carpeta de instalación y sigue las instrucciones en
pantalla (tarda varios minutos y necesita internet). Si la TV es Android TV, Google TV, Fire TV Stick o
vas a usar un mini PC por HDMI, no necesitas esto — esos métodos no usan el SDK de Tizen.

SI ALGO FALLA
---------------
- Si al instalar dice que no pudo instalar las dependencias: revisa que el
  PC tenga internet y ejecuta "reinstalar-dependencias.bat" dentro de la
  carpeta de instalación.
- Para ver qué está pasando o revisar errores, puedes abrir una ventana de
  símbolo del sistema (cmd) y ejecutar a mano:
    cd %LOCALAPPDATA%\CarteleraElBuenCorte
    node-runtime\node.exe server\index.js
  así ves los mensajes del servidor directamente en pantalla.
